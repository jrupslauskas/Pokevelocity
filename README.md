# README

Pokévelocity is a gamified productivity app that turns software development into a Pokémon-catching adventure. Complete your Jira tickets,
earn Pokéballs based on story points, and use them to catch all 151 original Pokémon. The harder your tickets and the faster your velocity, the more and better Pokéballs you'll earn
giving you higher catch rates and changes for rare and legendary Pokémon. Track your progress in your Pokédex, compete on the leaderboard with teammates, and prove you can truly code 'em all. Built for development teams who want to add a fun, nostalgic twist to sprint
velocity tracking.

This project is roughly 90% vibe coded garbage, but I hope it's at least fun

Upon spin up, the user activation code will be PALLET but you're encouraged to change that to a different 6 character string immediately

Run the app locally with `rails server` to give it a try
